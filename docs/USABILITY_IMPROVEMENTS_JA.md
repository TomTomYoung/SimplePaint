# シンプルな操作への改善と検証

更新日: 2026-09-13
基準: master `e7dc16d3d66623bb2ee5e5957f46a983fb51fec2`
対象: この文書を含む改善ブランチ。master への反映は PR のマージ後です。

## 方針

SimplePaint は、基本操作へすぐ届き、結果を予想でき、失敗しても戻せるペイントソフトを目指します。普段の画面には基本操作を置き、既存の特殊な道具と詳しい設定は必要なときに開きます。

## 実装した内容

1. 鉛筆、ブラシ、消しゴム、塗りつぶし、スポイト、選択、直線、四角、楕円、文字の10ツールを常時表示しました。その他の既存ツールは一つのメニューへまとめ、ツール検索を維持しました。
2. 基本設定として色、太さ、不透明度を表示し、図形・文字に必要な設定を加えています。追加設定とパレットJSONは折りたたみました。操作ガイドからイベント名などの内部用語を取り除きました。
3. 標準ブラシに効いていなかった滑らかさ・スタンプ間隔の設定を表示しなくしました。設定値を操作している間は入力要素を維持します。
4. 鉛筆、標準ブラシ、消しゴムには実際の描画処理を用いる見本と、ズーム倍率に対応する円形カーソルを追加しました。標準ブラシはクリックだけでも点を描けます。
5. 全消去、画像と選択範囲の反転、切り抜き、サイズ変更、レイヤー追加・削除・並べ替えをUndo/Redoの対象にしました。通常の描画は部分画像の履歴、構造を変える操作は文書全体の履歴を保持します。
6. 履歴の描画先を安定したレイヤーIDで特定します。追加・並べ替え・削除で過去の描画先がずれる問題と、削除で描画履歴まで消してしまう問題を修正しました。新規文書と復元時には前の文書の履歴を消去します。
7. キーボードのUndo/Redoを一か所で処理し、二重実行を修正しました。Ctrl+Shift+ZでもRedoできます。文字・数値入力中とダイアログ内では編集用ショートカットを横取りしません。
8. 画像保存は一つのボタンと形式選択ダイアログに統合しました。PNGが初期選択です。保存イベントの二重登録を取り除き、JPEGの透明部分を白くする処理も修正しました。画像ファイルの読込時は元画像の透明部分を維持します。
9. サイズ変更は幅と高さを一つのダイアログで入力します。「画像を拡大・縮小」は初期状態で縦横比を固定します。「余白を増減」は画像左上を固定し、右側と下側の領域を増減します。増えた部分は透明です。
10. 自由選択は矩形選択と同じ処理のため、ツール一覧と検索から外しました。既存の内部IDは残し、古い状態からのツール切替時は矩形選択として扱います。
11. スポイトで取得した色は直前の基本描画ツールへ渡し、その道具に戻ります。

## 自動保存・復元

PR #187 の `version: 2` レイヤースナップショット形式と実装を基に、今回のブランチで統合・修正しました。PR #187 自体をマージしたわけではありません。同PRを後からそのまま重ねると重複するため、残る差分を確認してください。

保存対象はキャンバス寸法、レイヤー別PNG、順序、ID、名前、表示、不透明度、合成方法、クリップ、種類、ベクターデータ、選択中のレイヤー、ツール設定です。旧形式の合成PNGスナップショットも復元できます。Undo/Redo履歴、選択範囲、未確定の文字や浮動選択は保存対象に含みません。

起動時は自動保存を停止し、前回の保存を調べてから開始します。保存がある場合は「前回の絵を復元」「新しく描く」を選びます。選ぶ前の白紙やページ終了処理で前回の保存を上書きしません。保存の確認に失敗した場合も、上書きを止めたまま画面に案内します。

復元では、全レイヤー画像の読込が成功してから文書を置き換えます。途中の画像が壊れている場合は、現在の文書と前回の保存を保持します。

## テスト

アプリ本体は従来どおり静的配信でき、実行時の追加パッケージは不要です。テスト用に `jsdom` と `@napi-rs/canvas` を開発依存へ追加しました。

```bash
npm install
npm test
```

Node.js 24.19.0で185件成功、失敗0件です。基準masterの148件中8失敗については、古いテストのdefaults参照、Node.jsのnavigatorプロパティ、DOMのない環境でのwindow参照を修正しました。読み込めるようになったテストと新しい統合テストを含むため、件数が増えています。

`test/integration/simple-workflow.test.mjs` はDOMイベントと実際のラスター画像を用い、クリック描画、ショートカットの一回実行、各種Undo/Redo、レイヤーの識別、レイヤー付き復元、破損時の保持、旧形式復元、JPEG背景、スライダー、スポイト、サイズ比率、自動保存停止、画面初期化を確認します。`git diff --check` も確認しています。

## マージ前に残る確認

実ブラウザでの表示と操作の目視確認は未実施です。今回のBrowser環境ではローカルHTTPサーバーへのアクセスが `ERR_BLOCKED_BY_CLIENT` で制限されました。DOMイベントとCanvasの統合テストは、ブラウザのレイアウトやIndexedDBの実機確認の代わりにはなりません。

```bash
python3 -m http.server 8000
```

`http://localhost:8000/` で、狭いウィンドウも含めたツール配置、メニューの重なり、パネル分割、カーソルの位置、保存ダイアログと一度だけのダウンロード、縦横比固定、再読込後のレイヤー復元を確認してください。

構造変更時の履歴は全レイヤーの画素を保持するため、大きい画像や多数レイヤーではメモリ使用量が増えます。全特殊ツールの描画品質、ベクター編集の完全なUndo/Redo、ベクター形状そのものの拡縮・反転の整合性、全ブラウザでの互換性は今回の確認範囲外です。
