# SimplePaint 開発文書案内

最終確認日: 2026-09-07

このフォルダは、利用者向け仕様、現在の進捗、開発者向け資料をまとめたものです。現状を短時間で把握する場合は、次の順番で読んでください。

1. `CURRENT_SPECIFICATION_JA.md`
   現在の `master` ブランチのコードから確認できる機能と制約を記載しています。

2. `PROGRESS.md`
   現在地点、テスト結果、未統合の Pull Request、既知の問題を記載しています。

3. `HANDOFF.md`
   次の担当者が着手する順番、検証方法、完了条件を記載しています。

4. `architecture_JA.md`
   モジュール構成と依存関係の詳細です。

5. `API_JA.md`、`tool-interface_JA.md`、`tool-development_JA.md`
   API、ツール契約、新しいツールの追加手順です。

6. `vector-tool-progress_JA.md`
   ベクターツール固有の進捗と未完事項です。

7. `SPECIFICATION_JA.md`
   2025-11-23 時点で作られた詳細仕様です。網羅性はありますが、ツール名や一部の実装状態が現在のコードと一致しない箇所があります。現状判断には `CURRENT_SPECIFICATION_JA.md` を優先してください。

## 判断の基準

この文書群では、次の三段階を区別します。

1. 実装済み
   `master` のコードと登録経路を確認できるものです。

2. テスト済み
   自動テストが存在し、2026-09-07 の確認で成功したものです。

3. 未検証または未統合
   コードが存在しても、テスト失敗、手動確認未実施、または未マージ Pull Request に属するものです。

GitHub Pages のデプロイ成功は静的サイトの公開成功を示しますが、アプリ全機能の正常動作を保証するものではありません。
