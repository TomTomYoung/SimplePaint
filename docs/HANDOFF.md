## 1. 現在地点

SimplePaint は、静的配信できる多機能ブラウザペイントとして、基本描画、78 個の登録ツール、レイヤー、選択、画像調整、Undo／Redo、画像入出力、クリップボード、オートセーブ、可変 UI を備えています。

一方で、`master` は回帰テストが全成功していません。さらに、レイヤー付きオートセーブと重複 DOM ID 修正を含む重要な PR #187 が未マージです。次担当は機能追加より先に、基準線の安定化と PR 整理を行ってください。

## 2. 最優先作業

### 2.1 `master` のテストを正常化する

2026-09-07 に Node.js 24.19.0 で `npm test` を実行した結果は、148 件中 140 件成功、8 件失敗でした。

失敗原因は三系統です。

1. `test/core/store.test.mjs` が `toolDefaults` を import していますが、`src/core/store.js` はこれを export していません。

2. `test/helpers/mock-dom.js` が `globalThis.navigator` へ単純代入しており、Node.js 24 の getter-only プロパティに対して失敗します。この影響でレイヤーパネル、調整マネージャー、マニフェストのテストが失敗します。

3. `src/gui/tool-props.js` の末尾が無条件に `window.initToolPropsPanel` を設定するため、DOM のない Node 環境で `window is not defined` になります。この影響でベクターツール系テストが失敗します。

完了条件は、サポート対象として決めた Node.js バージョンで `npm test` が全成功し、修正がブラウザ実行を壊していないことです。

### 2.2 PR #187 を検証して統合判断する

PR #187 `Clean up runtime IDs and add layered autosave snapshots` は、2026-07-02 更新、17 コミット、13 ファイル変更、GitHub 上ではマージ可能です。

主な内容は次のとおりです。

1. 重複している `addLayerBtn` と `addVectorLayerBtn` を起動前に正規化します。

2. ツールバーと右パネルのレイヤー追加イベントを分離します。

3. オートセーブを、合成 PNG 一枚の旧形式からレイヤー別画像・メタデータ・ストアを持つ version 2 形式へ拡張します。

4. 旧形式の復元互換を維持します。

5. 新形式と DOM ID 正規化のテスト、仕様文書を追加します。

PR 本文にはローカルテスト未実行と明記されています。マージ前に次を確認してください。

1. PR ブランチ上で `npm test` を実行し、既存 8 失敗との関係を切り分けます。

2. 二つのレイヤー追加ボタンがそれぞれ一回だけ動作することを確認します。

3. 複数のラスター／ベクターレイヤーを保存し、再読込後に順序、名前、表示、不透明度、合成モード、クリップ、アクティブレイヤー、ベクターデータが復元されることを確認します。

4. 旧形式スナップショットを復元できることを確認します。

5. 大きな文書で保存時間と IndexedDB 使用量を観測します。

6. version 2 でも Undo／Redo と選択状態は保存しない仕様でよいか確認します。

静的 HTML の ID を直接修正するスクリプトと、起動時正規化の両方が含まれています。最終的には HTML を一意 ID に直し、起動時正規化は旧マークアップ互換として残すか削除するかを決めてください。

## 3. 次の機能優先順位

基準線と PR を整理した後は、次の順番を推奨します。

1. ベクター編集の Undo／Redo 統合
   アンカー移動、挿入、削除、パス移動、スタイル変更を一貫した履歴単位にします。

2. 編集可能な文書形式
   PR #187 の version 2 スナップショットを土台に、手動保存・読込できる独自形式へ発展させます。オートセーブ内部形式とユーザー文書形式は、バージョニングと移行規則を明示してください。

3. 自由選択の実装
   `select-free` は現在、矩形選択と同じファクトリです。独立したポリゴン／投げ縄選択を実装するか、UI から未完成項目を外します。

4. ベクター SVG の改善
   曲線、閉路、塗り、線、変換、図形プリミティブを保持できる出力にします。

5. 統合テスト
   各ツールの単体テストだけでなく、文書作成、レイヤー操作、描画、Undo、保存、復元の連続操作を検証します。

6. 未登録コードの整理
   `src/tools/drawing/clone_stamp.js` はマニフェスト未登録です。実装して登録するか、将来予定として明示するか、不要なら削除候補にします。

## 6. 変更時の注意

1. `src/core/layer.js` の `layers` と `activeLayer` はモジュール共有状態です。文書復元やテストで直接変更する場合、レイヤー一覧、合成結果、ストア、選択、履歴を同期させてください。

2. ツール ID はマニフェスト、ツールプロパティ定義、HTML／GUI、ショートカット、LocalStorage にまたがります。名称変更時は旧 ID の移行も検討してください。

3. Canvas のピクセル操作は大きな画像で高コストです。全画面コピーや全レイヤー PNG 化を入力イベントごとに行わないでください。

4. Clipboard API、IndexedDB、LocalStorage は権限、容量、プライベートブラウジングの影響を受けます。失敗経路を維持してください。

5. GitHub Pages の成功だけで完了とせず、`npm test` と主要ブラウザでの手動確認を分けて記録してください。
