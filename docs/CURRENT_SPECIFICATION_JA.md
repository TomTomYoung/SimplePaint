# SimplePaint 現行仕様

最終確認日: 2026-09-07
対象ブランチ: `master`

## 1. 製品の位置づけ

SimplePaint は、ブラウザ上で動作するフレームワークレスのペイントアプリケーションです。HTML、CSS、ES Modules、Canvas 2D API で構成され、ビルド工程なしで静的配信できます。

実装の中心は、複数ラスター／ベクターレイヤー、選択、描画ツール、図形・曲線ツール、画像調整、Undo／Redo、画像入出力、クリップボード、オートセーブ、可変ワークスペースです。

## 2. 実行方法

ES Modules を使用するため、`index.html` を `file://` で直接開く方法ではなく、リポジトリのルートを HTTP サーバーで配信します。

```bash
python3 -m http.server 8000
```

起動後に `http://localhost:8000/` を開きます。依存パッケージのインストールやビルドは不要です。

テストは Node.js の標準テストランナーを使用します。

```bash
npm test
```

`package.json` のバージョンは `0.0.0` で、公開パッケージではありません。ライセンスファイルはありません。

## 3. 画面構成

画面はヘッダー、左ペイン、中央キャンバス、右ペイン、フッターで構成されます。

1. ヘッダー
   ファイル操作、Undo／Redo、クリップボード、表示操作、レイヤー操作、画像調整、ツールドロップダウンを持ちます。高さはドラッグで変更でき、状態は保存されます。

2. 左ペイン
   ツール選択部とツールプロパティ部を持ちます。両者の境界とペイン幅は変更でき、選択ツールや開閉状態を保存します。

3. 中央キャンバス
   合成済み表示用キャンバスとオーバーレイを重ね、ズーム、パン、選択範囲、ツールプレビューを扱います。

4. 右ペイン
   レイヤー一覧、検索・種別フィルター、レイヤー追加・削除、レイヤープロパティを持ちます。レイヤーのサムネイル表示は削除されています。

5. フッター
   ステータス、ズーム、オートセーブ状態、レイアウトプリセット、ショートカット一覧を表示します。

## 4. コア構成

1. `src/app.js`
   アプリケーションの組み立て、ツール登録、UI 初期化、文書初期化を担当します。

2. `src/core/engine.js`
   ポインター入力、選択、ツール実行、描画要求、履歴適用、キャンバス表示を統括します。

3. `src/core/store.js`
   現在のツール ID、ツール別設定、共有ベクター状態を保持します。購読、選択的監視、状態置換、ツール状態の初期化を提供します。

4. `src/core/layer.js`
   レイヤー配列、アクティブレイヤー、追加、削除、並べ替え、合成を担当します。

5. `src/core/viewport.js`
   ズーム、パン、座標変換、画面へのフィット、表示範囲制約を担当します。

6. `src/managers/history-manager.js`
   パッチ型の履歴、Undo／Redo、履歴上限、メタデータ、変更通知を担当します。既定上限は無制限です。

## 5. ツール

`src/tools/base/manifest.js` には 78 個のツール ID が登録されています。

1. 選択: 2 個
   `select-rect`、`select-free`。ただし `select-free` は現在 `select-rect` と同じファクトリを使用しており、自由選択の独立実装ではありません。

2. 描画: 23 個
   鉛筆、ブラシ、フリーハンド、ピクセルブラシ、ぼかし、グラデーション、ハッチング、予測ブラシ、対称描画、消しゴムなどです。

3. 特殊ブラシ: 28 個
   水彩、カリグラフィ、リボン、多毛筆、エアブラシ、散布、スマッジ、チョーク、ドリップ、グリフ、粒状化、ハーフトーン、HDR、マスク、ワープなどです。

4. ベクター: 6 個
   ベクター描画、保持、ベクタライズ、編集、パス論理演算、ストロークのアウトライン化です。

5. 曲線: 10 個
   二次／三次 Bézier、Catmull–Rom、B-spline、NURBS と、それぞれの編集版です。

6. 図形: 6 個
   円弧、扇形、楕円、直線、矩形、標準楕円です。

7. 塗りつぶし・色取得: 2 個
   バケツとスポイトです。

8. テキスト: 1 個
   Canvas 上のテキスト入力です。

`src/tools/drawing/clone_stamp.js` はファイルだけが存在し、マニフェスト未登録のため利用できません。

## 6. ツール拡張契約

ツールはファクトリ関数から生成され、少なくともポインターイベント用のハンドラーを提供します。登録元は `src/tools/base/manifest.js`、生成と登録は `src/tools/base/registry.js` が担当します。

新規ツール追加時は、実装ファイル、マニフェスト登録、必要なプロパティ定義、UI 表示、テストを一組として変更します。詳細は `tool-interface_JA.md` と `tool-development_JA.md` を参照してください。

## 7. レイヤー

レイヤーは Canvas 要素にメタデータを付加する方式です。名前、表示状態、不透明度、合成モード、クリッピング、レイヤー種別、ID を保持します。

対応種別は `raster`、`vector`、`text` です。現在の主要な描画結果はラスター Canvas に保持され、ベクター編集データは共有ストアおよびベクターレイヤーのメタデータとして扱われます。

レイヤーの追加、ベクターレイヤー追加、削除、選択、並べ替え、名称変更、表示切替、不透明度、ブレンドモード、クリッピングが実装されています。

## 8. ベクター機能

ベクターツールはパス作成、アンカー表示、既存アンカーのドラッグ、アンカーの挿入・削除、パス移動、スナップ、簡略化、ラスター化、簡易 SVG 出力を持ちます。

現時点の制約は次のとおりです。

1. SVG 出力は単純な `M/L` を中心とし、全曲線・全図形プリミティブを保持する完全なベクター書き出しではありません。

2. 複数アンカー選択や専用のセグメント分割 UI は未完成です。

3. ベクター編集全体の Undo／Redo 統合は十分に検証されていません。

## 9. 選択、クリップボード、画像調整

矩形選択と浮動選択を扱います。コピーはアクティブレイヤー単位または表示レイヤー合成単位で取得でき、選択がある場合は範囲に切り詰めます。貼り付けた画像は浮動選択として配置されます。

画像調整は選択または対象レイヤーに対してプレビューし、確定時に履歴へ登録します。共通画像処理ユーティリティには、畳み込み、ボックス／ガウシアンぼかし、アンシャープ、グレースケール、エッジ検出、ヒストグラム、二値化、形態学処理があります。

Clipboard API はブラウザの権限とセキュアコンテキスト制約を受けます。

## 10. ファイル入出力

画像ファイルを読み込んで新規文書へ配置できます。書き出し形式は PNG、JPEG、WebP です。書き出しは表示レイヤーを合成した単一画像であり、編集可能なレイヤー構造を持つ独自ファイル形式は `master` にありません。

## 11. オートセーブ

オートセーブは IndexedDB の `paintdb` データベース、`kv` ストア、`autosave` キーを使用します。既定では 15 秒間隔に加え、状態更新後にデバウンス保存します。

現在の `master` が保存する内容は、全表示レイヤーを合成した PNG、幅、高さ、時刻、共有ベクター状態です。ラスターのレイヤー構造、Undo／Redo 履歴、選択状態は復元できません。

レイヤー構造を保存する version 2 スナップショットは PR #187 に実装されていますが、未マージです。

## 12. 永続化される UI 状態

安全な LocalStorage ラッパーを介し、最後に選択したツール、パネルの開閉、レイヤーフィルターと検索語、パネル寸法、ヘッダー寸法、ワークスペースレイアウトなどを保存します。ストレージが使用できない環境ではメモリ側へフォールバックします。

## 13. テストと配信

テストは `node --test` で実行します。対象はイベントバス、ストア、ビューポート、レイヤーパネル、オートセーブ、調整、履歴、ツールマニフェスト、ベクター、数学・色・画像・幾何・パス・ノイズなどです。

2026-09-07 の Node.js 24.19.0 での結果は、148 件中 140 件成功、8 件失敗です。したがって、現状を「全テスト成功」とは扱いません。失敗の詳細は `PROGRESS.md` と `HANDOFF.md` に記載しています。

GitHub Pages の最新 `master` デプロイは成功しています。ただし Pages のワークフローはアプリケーションテストを実行していません。

## 14. 現時点で保証しない事項

1. モバイル端末と主要ブラウザ全組み合わせでの互換性
2. 大きな画像や多数レイヤーでの性能・メモリ上限
3. 全 78 ツールの目視品質と全操作の統合動作
4. 編集可能なプロジェクトファイルの保存・読込
5. 完全な自由選択
6. 完全な SVG 往復編集
7. アクセシビリティの総合監査
8. 全テスト成功
